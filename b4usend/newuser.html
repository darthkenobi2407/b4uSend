youre gonna need a computer for this, follow the instructions given here on Chrome or Microsoft Edge to install the extension manually

1. Download the extension

Open the GitHub link above, click the green "Code" button and chose "Download ZIP"

then , once it's downloaded, extract the ZIP file and find the folder which has manifest.json

Thats the folder youll need in the next steps , dont select the src folder unless it contains the extensions manifest(usually it will but just in case)

2. Adding it to Chrome

01. Open extensions

Type chrome://extensions into ur address bar

02. Turn on Developer mode

Find the Developer mode switch in the top ryt corner and turn it on (slider type swicth)

03. Load b4usend

Click "Load unpacked", select the folder containing manifest.json and confirm it

If it loads without errors, youre good to go

04. Pin it(if you want to )

Click the puzzle type piece icon next to Chromes address bar and pin b4usend so it's easy to fin it later
