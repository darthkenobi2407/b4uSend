Getting started

Here's how to install b4usend on your browser. It only takes a couple of minutes.

Want to try it before installing? Try the analyzer →

Get the files from GitHub →

You'll need a computer for this. The instructions below use Chrome or Microsoft Edge and install the extension manually.

1. Download the extension

Open the GitHub link above, click the green Code button and choose Download ZIP.

Once it's downloaded, extract the ZIP file. Open the folders until you find manifest.json.

That's the folder you'll need in the next steps. Don't select the src folder unless it contains the extension's manifest.

2. Add it to Chrome

01. Open extensions

Type chrome://extensions into your address bar.

02. Turn on Developer mode

Find the Developer mode switch in the top-right corner and turn it on.

03. Load b4usend

Click Load unpacked, select the folder containing manifest.json and confirm.

If it loads without errors, you're good to go.

04. Pin it

Click the puzzle-piece icon next to Chrome's address bar and pin b4usend so it's easy to find.

Using Microsoft Edge?

The process is almost the same. Open edge://extensions, enable Developer mode, click Load unpacked and select the same extension folder.

That's it.

Click the b4usend icon in your browser to open it. If something goes wrong, check the error shown on the browser's extensions page.
