Get started with b4usend.

A quick step-by-step guide to installing the browser extension and getting it ready to use.

Before you begin

You'll need the b4usend extension files downloaded to your computer. This guide explains how to load the extension manually in Chrome or Microsoft Edge.

Get b4usend on GitHub ↗
Important: Download the repository as a ZIP and extract it first. Opening the GitHub page or hosting the HTML files on a website does not install the browser extension.

Installing on Google Chrome

1

Download the files

Open the GitHub repository, click the green Code button, and select Download ZIP.

2

Extract the ZIP

Find the downloaded ZIP file and extract it. Open the folders until you find the extension's manifest.json file.

In this repository, the extension's main folder is expected to be b4usend. Select the folder containing manifest.json, not the src folder.

3

Open Chrome's extension manager

Enter this address into Chrome's address bar:

chrome://extensions

4

Turn on Developer mode

Find the Developer mode switch near the top-right corner of the extensions page and turn it on.

5

Load b4usend

Click Load unpacked, select the extracted extension folder containing manifest.json, and confirm your selection.

If Chrome displays an error, check the error details on the extension card. The manifest and referenced file paths must be valid.

6

Pin the extension

Click the puzzle-piece icon in Chrome's toolbar. Find b4usend and click the pin icon to keep it visible.

Click the b4usend icon to open its popup.

Installing on Microsoft Edge

1

Open Edge extensions

Enter edge://extensions in the address bar.

2

Enable Developer mode

Turn on Developer mode on the extensions page.

3

Load the extension

Click Load unpacked and select the extracted b4usend folder containing manifest.json.

You're all set.

Once the extension has loaded successfully, open it from your browser toolbar. If b4usend includes configurable settings, open its extension details or options page to customize them.

Need to check the source files again?

Visit GitHub repository ↗
