Extension settings and installation guide

Install b4usend

Follow the instructions below to install b4usend in a Chromium-based browser.

Before you start: You need the extension's actual files on your computer. A GitHub repository or a Vercel website URL is not itself an installed browser extension.

Google Chrome

1

Download the extension

Open the b4usend GitHub repository and download the project files using the Code button, then Download ZIP.

Open b4usend on GitHub →

2

Extract the ZIP file

Find the downloaded ZIP file on your computer, right-click it, and select Extract All.

Open the extracted folders until you find manifest.json.

Select the b4usend folder containing manifest.json, not the outer GitHub repository folder and not the src folder.
3

Open Chrome Extensions

Type this into Chrome's address bar:

chrome://extensions

4

Enable Developer mode

Turn on the Developer mode switch near the top-right corner of the Extensions page.

5

Load the extension

Click Load unpacked. Select the extracted b4usend folder containing manifest.json, then click Select Folder.

6

Pin b4usend

Click Chrome's puzzle-piece Extensions icon, find b4usend, and click the pin icon if you want it visible in your toolbar.

Microsoft Edge

1

Open the Extensions page

edge://extensions

2

Load b4usend

Turn on Developer mode, click Load unpacked, and select the extracted b4usend folder containing manifest.json.

Having trouble? If the browser displays an error, open the extension's card on the Extensions page and read the error details. The extension may need its manifest or permissions corrected before it can run.
